# GTA III/Vice City/San Andreas Blow Up All Cars Cheat Player Immunity Mod

This mod ensures that when the cheat to blow up all cars is activated, the player's vehicle remains unaffected, similar to how it works in the Definitive Edition.

# Installation

**III**:

1. Install the Ultimate Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.3..Blow.Up.All.Cars.Cheat.Player.Immunity.v1.0.zip"
3. Copy the "Blow Up All .Cars Cheat Player Immunity" folder into the "modloader" folder, which is located in your game's root directory.
4. Done

**VC**:

1. Install the Ultimate Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.VC.Blow.Up.All.Cars.Cheat.Player.Immunity.v1.0.zip"
3. Copy the "Blow Up All Cars Cheat Player Immunity" folder into the "modloader" folder, which is located in your game's root directory.
4. Done

**SA**:

1. Install the Silent's Asi Loader and Modloader in in the game's root folder
2. Extract the file "GTA.SA.Blow.Up.All.Cars.Cheat.Player.Immunity.v1.0"
3. Copy the " Heavy Weapons Sprint" folder into the "modloader" folder, which is located in your game's root directory.
4. Done
